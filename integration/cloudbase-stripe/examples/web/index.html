pay-stripe 示例 — Checkout 下单与退款

流程：create_session 拿到 url → 跳转 Stripe 托管收银台 → 支付完成回跳到本页并带 session_id → 自动查状态。

云函数地址与登录态

云 API 入口由网关验签 AccessToken，函数只认网关注入的身份（x-userid + x-authmethod）；未登录会返回 401。

订单参数
退款（可选）

只对 payment_status=paid 的 Session 生效，且只能退自己的单（服务端比对 metadata.cloudbaseUid）。 返回 succeeded 即退款成功；账务状态以 Webhook charge.refunded 落库为准（需在 Stripe 后台订阅该事件）。 异步退款方式可能先返回 pending，由 refund.updated 推进到终态。

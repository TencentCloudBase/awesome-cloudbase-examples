# 集成中心接入

虚拟支付涉及双签名与多类事件推送，自建成本高，**优先走集成中心模板**。

## 集成承担什么

| 能力 | 由谁提供 |
|---|---|
| 凭证托管与密钥隔离 | 集成中心（环境变量注入，代码不出现明文） |
| 模板云函数生成 | 集成中心 |
| **回调域名与验签解密链路** | 集成中心网关 |
| 事件订阅 | 集成中心 |
| 道具清单（productId + 价格） | **业务侧维护**，须与 MP 后台一致 |
| 幂等发货、订单状态机、风控 | **业务侧实现** |

## 创建后的资源

提交后平台异步完成（**约 1–2 分钟**）：

| 资源 | 形态 |
|---|---|
| HTTP 云函数 | `<集成名>-<随机串>` |
| 环境变量 | 平台注入凭证 |
| **回调域名** | `https://<集成标识>.integration-callback.tcloudbase.com` |
| **回调路由** | 平台预置 |

## 回调链路

```
微信平台 ──事件推送──> 回调网关
                          │ ① 来源认证（Token SHA1 验签）
                          │ ② 拉取集成信息
                          │ ③ 验签
                          │ ④ 解密（安全模式 AES-256-CBC）
                          │ ⑤ 写入 header → 转发
                          ▼
                     集成函数（取明文 → 幂等 → 发货 / 回收 → 应答）
```

**`notifyURLCallbackType=system` 时五件事全部收敛在网关侧。** 业务函数只处理领域逻辑，代码中不出现 Token / EncodingAESKey。

> `notifyURLCallbackType=ownservice` 时不走网关：URL 由业务方自己填在【虚拟支付 → 基本配置 → 基础配置 → 发货推送配置】，验签与解密由业务函数完成（模板 `app.js` 已内置，配 `token` + `msgSecret` 即生效）。
>
> 模式由平台字段声明 + 请求自带标记（`Encrypt` / `echostr`）双重判定，不需要业务侧再造一个开关。

## 验签口径（网关侧）

| 场景 | 待签参数 | 算法 | 校验对象 |
|---|---|---|---|
| 配置 URL 的 GET 探测 | Token + timestamp + nonce | SHA1 | `signature`，通过后原样返回 `echostr` |
| 接收推送 POST（明文/兼容） | Token + timestamp + nonce | SHA1 | `signature` |
| 接收推送 POST（**安全模式**） | Token + timestamp + nonce + Encrypt | SHA1 | **`msg_signature`**（不能用 `signature`） |

## 解密规则（安全模式）

- `AESKey = Base64_Decode(EncodingAESKey + "=")`，EncodingAESKey 为 **43 位**，补 `=` 后解码得 **32 字节**
- 算法 **AES-256-CBC**，IV 取 AESKey **前 16 字节**，PKCS#7 填充
- 拆包：`random(16B) + msg_len(4B 网络字节序) + msg + appid`，从第 20 字节起读 `msg_len` 长度
- 校验拆出的 `appid` == 本小程序 AppID

## 集成侧必须登记的信息

| # | 项目 | 说明 |
|---|---|---|
| 1 | 回调落点 | 平台生成，业务侧不自建公网域名 |
| 2 | **回调承接资源** | 转发到哪个云函数；**不绑定则推送无处可转** |
| 3 | Token | 虚拟支付**发货推送**的验签凭据，须与后台「开发管理 → 消息推送」里的 Token 一致 |
| 4 | EncodingAESKey | 43 位，解密凭据 |
| 5 | 加解密方式 + 数据格式 | 明文/兼容/安全 + XML/JSON |
| 6 | 事件订阅 | 订阅哪些 `xpay_*` 事件 |

> 提交虚拟支付「发货推送配置」时，微信会**立即发起 GET 探测**，所以必须**先创建集成、再提交配置**。

## 🚨 集成边界（改造时绕开）

- **云函数随机串不可改** —— 与回调域名子域、内置环境变量绑定，**改名即断回调**
- **回调路由由平台预置** —— 不要改路径
- **删除集成 ≠ 删除云函数** —— 删除集成会释放回调域名与回调路由（**不可恢复**），云函数与环境变量保留
- **改配置会重新部署**（约 1–2 分钟），期间进行中的请求可能受影响
